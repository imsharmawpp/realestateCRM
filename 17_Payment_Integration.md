# Payment Gateway

## Primary Gateway

- Razorpay

## Payment Features

- Booking amount
- EMI payment tracking
- Partial payment
- Full payment
- Refund management
- Invoice generation
- Payment receipts
- Webhook verification

## Payment Flow

1. Create booking order
2. Create Razorpay order
3. Redirect or open payment checkout
4. Capture payment response
5. Verify signature
6. Update transaction status
7. Update booking status
8. Send confirmation by email and WhatsApp

## Accounting Fields

- Base amount
- GST amount, if applicable
- Gateway charges
- Discount
- Refund amount
- Invoice number
- Receipt number
