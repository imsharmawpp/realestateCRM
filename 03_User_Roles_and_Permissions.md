# User Roles and Permissions

## Super Admin

The Super Admin has full system access.

### Permissions

- Manage properties
- Manage agents
- Manage customers
- Manage leads
- Manage CRM activities
- Manage bookings
- Manage payments
- Manage WhatsApp templates
- Manage email templates
- View all reports
- Configure system settings
- Manage roles and permissions

## Admin / Manager

The Admin or Manager operates day-to-day business workflows.

### Permissions

- Approve or reject property listings
- Assign leads to agents
- Monitor agent performance
- Manage enquiries
- Review bookings
- View reports
- Handle escalations

## Agent

Agents work on assigned leads and properties.

### Permissions

- Add property, if enabled by admin
- Edit assigned properties
- Manage assigned leads
- Add follow-up notes
- Send WhatsApp messages
- Send email messages
- Schedule visits
- Update property status
- View own commission reports

## Customer

Customers use the public portal and customer dashboard.

### Permissions

- Register and log in
- Save properties
- Book properties
- View bookings
- Upload documents
- View payment history
- Chat or enquire with agent
- Manage profile

## Optional Roles

- Builder
- Broker
- Channel partner
- Property owner
- Finance team
- Support executive
