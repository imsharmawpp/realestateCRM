# WhatsApp Integration

## Supported Provider Options

- Meta WhatsApp Business API
- Interakt
- AiSensy
- WATI

## Automated Messages

- Lead received
- Property inquiry acknowledgement
- Site visit reminder
- Booking confirmation
- Payment reminder
- Follow-up reminder
- Agent assignment notification
- Brochure delivery

## Template Management

- Store templates in CRM
- Track provider template IDs
- Support variables such as customer name, property title, agent name, visit date, and payment link
- Maintain approval status
- Log every outbound message

## Click-to-Chat Tracking

Track WhatsApp click events from property pages, listing cards, floating buttons, and campaign landing pages to measure lead source effectiveness.

## Compliance Notes

- Use approved templates where required by the provider
- Respect customer consent and opt-out requests
- Store message logs for audit and dispute resolution
