# Real Estate Website + CRM System

## Project Goal

Build a complete Indian Real Estate Portal and CRM that allows customers, agents, admins, builders, and business owners to manage the full property discovery and sales lifecycle.

## Core Capabilities

- Buy properties
- Sell properties
- Rent properties
- Commercial property listings
- New launch project listings
- Property booking workflows
- Lead management
- CRM activity tracking
- WhatsApp automation
- Email automation
- Agent management
- Customer dashboard
- Admin dashboard
- Booking and payment history
- Enquiry management

## Technology Stack

### Frontend

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- AJAX

### Backend

- PHP 8.2+
- MySQL 8
- MVC-style application structure
- REST-style JSON APIs for asynchronous actions

### Server

- Hostinger Shared Hosting
- Apache with `.htaccess` routing
- SSL certificate
- Cron jobs for follow-ups, reminders, and automation queues

### Integrations

- WhatsApp Business API or approved provider APIs
- SMTP email
- Razorpay
- Google Maps
- Google Analytics
- Google Search Console

## Business Outcome

The platform should centralize property inventory, website leads, agent activity, enquiries, bookings, automated communication, and reporting so a real estate business can scale operations without losing follow-up discipline or lead visibility.
