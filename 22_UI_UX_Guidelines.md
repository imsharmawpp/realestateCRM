# UI/UX Guidelines

## Theme

Use a modern real estate interface with clean cards, high-quality property visuals, easy filtering, and prominent enquiry actions.

## Colors

- Primary: `#0D6EFD`
- Secondary: `#1E293B`
- Accent: `#22C55E`
- Background: `#F8FAFC`
- Text: `#0F172A`

## Font

- Poppins
- System fallback fonts for performance

## Responsive Breakpoints

- Desktop
- Tablet
- Mobile

## Component Guidelines

- Property cards with price, location, image, status, and CTA
- Sticky mobile CTA for call and WhatsApp
- Clear form validation
- Dashboard widgets with concise metrics
- CRM pipeline with color-coded stages
- Accessible contrast and keyboard navigation

## UX Priorities

- Fast search
- Minimal enquiry friction
- Trust-building content
- Clear booking status
- Simple agent workflows
