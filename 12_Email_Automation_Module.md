# Email Automation

## SMTP Options

- Hostinger Email
- SendGrid
- Mailgun
- Any authenticated SMTP provider supported by PHP mail libraries

## Automations

- Lead received
- Property details
- Visit reminder
- Booking confirmation
- Payment reminder
- Invoice email
- Password reset
- Account verification

## Template Requirements

- Subject line
- HTML body
- Plain-text fallback
- Dynamic variables
- Attachment support for brochures and invoices
- Active/inactive status

## Logging

Each email should create a delivery log containing recipient, template, related lead or booking, status, provider response, and timestamp.
