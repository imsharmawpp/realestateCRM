# Business Requirements

## Customer Features

### Property Search

Customers must be able to search and filter properties by:

- City
- State
- Location or locality
- Budget range
- BHK configuration
- Property type
- Furnishing status
- Ready-to-move status
- Under-construction status
- Builder or project name
- Amenities
- Possession timeline

### Property Details

Each property detail page should include:

- Image gallery
- Videos
- Virtual tour or 360-degree walkthrough link
- Brochure download
- Google Maps location
- Amenities
- Floor plans
- Pricing details
- Unit availability
- Similar properties
- Agent contact options

### Lead Generation

The portal must capture leads through:

- Schedule visit form
- Request callback form
- WhatsApp inquiry button
- Email inquiry form
- Brochure download form
- Price request form
- Contact agent form

### Property Booking

The booking module should support:

- Booking amount
- Full payment
- Installment payment
- Booking confirmation
- Agreement upload
- KYC document collection
- Payment receipts

## Admin Features

Admins must be able to manage properties, leads, agents, customers, bookings, payments, communication templates, reports, and system settings from a secure dashboard.

## Agent Features

Agents must be able to view assigned leads, update lead statuses, add activities, schedule site visits, send WhatsApp/email follow-ups, and monitor commissions.
