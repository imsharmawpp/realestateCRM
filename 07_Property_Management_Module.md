# Property Management

## Features

- Add property
- Edit property
- Delete or archive property
- Upload images
- Upload videos
- Upload floor plans
- Upload brochure PDF
- Manage amenities
- Manage price and availability
- Manage SEO metadata
- Assign property to agent
- Approve submitted listings

## Property Status

- Available
- Sold
- Rented
- Reserved
- Draft
- Pending Approval
- Inactive

## Property Types

- Apartment
- Villa
- Plot
- Commercial
- Office
- Warehouse
- Shop
- Farmhouse
- Builder floor

## Validation Requirements

- Required title, city, location, price, and property type
- Unique URL slug
- Image size and format validation
- PDF-only brochure upload
- Numeric validation for area and price fields
- Admin approval before public listing when submitted by agents or owners
