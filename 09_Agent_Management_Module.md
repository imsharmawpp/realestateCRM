# Agent Management

## Agent Dashboard

Agents should get a focused workspace containing assigned leads, assigned properties, visit schedules, reminders, commissions, and communication tools.

## Features

- Lead assignment
- Property assignment
- Performance report
- Commission tracking
- Availability status
- Agent profile management
- Daily task list
- Site visit calendar
- Customer follow-up history

## Reports

- Daily leads
- Monthly leads
- Conversion ratio
- Follow-up pending report
- Site visits completed
- Bookings closed
- Commission earned

## Manager Controls

- Assign or reassign leads
- Limit property visibility by city or team
- Monitor response times
- Disable inactive agents
- Review communication history
